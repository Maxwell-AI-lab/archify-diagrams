经验的复利

RLinf 团队的第二落子：从训练框架（RLinf）到运行时中枢（RPent）。RPent（Recursive Physical Agent）把「GPT-6 Astra / Claude Code 当规划器 + VLA/WAM 当手 + 三层记忆当复利」组装成开源具身智能体基础设施：LIBERO-PRO 八套件总成功率 92.63%（741/800），记忆让位置交换任务 31.0%→87.0%，Flash Mode 把端到端耗时 283.6s→40.9s（约 7×）。本报告逐层拆它的四层架构、MCP/RPC/MHS 三接口、记忆与任务卡机制，并放进本月的外脑三部曲里读——它是「GPT-as-Policy 裁判形态」的下一步：裁判 + 教练 + 台账，经验第一次成了可复利的资产。

一句话定位坐标

RPent 回答的问题是：「在基座模型冻结的前提下，具身智能体的能力上限由什么决定？」它的答案：由经验的复利方式决定——规划器可以换（GPT-6 Astra / Opus / Claude Code 都行）、手可以换（π₀.₅ / RLDX-1 / LingBot / DreamZero），但「验证过的经验如何被记录、升级、隔离、复用」是这个系统的真骨架。论文锚点 Harness VLA（arXiv 2607.08448），Apache-2.0 开源，647 stars。

事实分档：仓库级（GitHub README 与 readthedocs 排行榜，数字为官方口径）与媒体级（量子位授权发布，用于机制描述）。仓库今天仍在活跃推送——这是一个正在跑的项目，不是论文存档。

四层架构：智能层与环境层完全解耦骨架

MCP / RPC / MHS：组合接口的标准化提前到来了接口

我们在趋势判断里说「12-24 个月内，三层栈的组合接口会成为争夺点」——RPent 把它提前做出来了，而且拆成了三份：MCP 管「能力怎么被描述」、RPC 管「服务怎么互联」、MHS 管「物理设备怎么读写」。MHS 的野心值得注意：不止机器人，还包括仪器、家居、工业设备——这是在定义「物理世界的 function calling」。

记忆系统：复利的账本怎么记核心

三层记忆按复用范围分层；每条记录带 scope / type / confidence / evidence 四个字段；新经验要通过验证才能升级置信度；冲突记录隔离保存不互相覆盖；可迁移的是 Recipe（任务逻辑）而不是固定坐标；探索模式可写、评测模式只读冻结。这一节是全系统设计密度最高的地方——它就是 Astar「演化史」的运行时版。

Flash Mode：把经验压缩成任务卡7×

探索期（慢、完整）验证过的成功流程被压缩成 Task Card——任务阶段、动作原语、关键目标、检查条件，不含固定坐标。闪电期直接按卡执行，视觉重定位对齐场景，只有检查失败或环境偏离时才召回规划器。这就是 DeepSeek Engram 的「196B 条件记忆」在任务层的直系亲属：常用流程存外周，昂贵的深思按需调用。

对我们知识地图的六个接口连接

① 组合接口标准化的第一枪。趋势判断说 12-24 个月内「意图怎么下发、谁接管」会成为争夺点——RPent 的 MCP/RPC/MHS 把它拆成了发现/连接/触达三层，且 MHS 的触角伸向机器人之外的物理设备。谁定义物理世界的 function calling，谁就拿到了具身侧的操作系统位——这场仗现在开打了。

② 记忆是 System-2 缺口的第一块砖，且比想象中早到。我们以为第三层要从「深思」补起，RPent 显示「先补记忆」更划算：31%→87% 的增益不需要更聪明的规划器，只需要把验证过的经验留下来。深思可以慢点来，遗忘不能等。

③ Task Card 是吸收曲线的下一跳。外周任务卡 → 蒸馏语料 → 进权重，路径和 GPT-as-Policy 的 14.4% 纠错数据、Astar 的演化史完全同构：外脑时期攒的每一类数据，都是吸收时期的训练集。

④ RLinf 生态的方法论闭环。训练侧 RLinf（支持昇腾）+ 运行时 RPent + 考场 LIBERO-PRO/RoboDojo + 对照组 πRLinf——这支团队同时握着训练、运行、评测三件套，等于把「具身训练基础设施」这个卖铲子位从训练扩展到了全生命周期。这是你方向判断里那条「押基础设施」路线的活样本。

⑤ WAM 首次成为一等公民。RPent 的动作原语列表里 DreamZero（WAM）和 VLA 并列——用户侧的 WAM 路线第一次有了现成的接入位：实现 RPent 的原语接口，你的 WAM 就能被 GPT-6/Claude Code 调度。这是接入生态最便宜的时机。

⑥ 两个时钟的脚手架解。「语言侧分钟级 vs 具身侧周月级」的时差问题，RPent 用任务卡给出了系统层答案（7×）——不是让物理变快，而是让昂贵的深思按需出场。这为具身侧争取到了与语言侧对齐的迭代节奏。

给自己的行动清单落地

四件事按优先级：①跑通 RPent 的 LIBERO-PRO 复现（它就是 RLinf 生态，910B 上 πRLinf 已有先例；CLI 形态和 Claude Code 一致，上手成本低）——拿到自己环境下的外脑基线。②把 CyberGym 的验证纪律映射进 RPent 评测模式：它的「评测只读冻结」与 S1-S3 分级验证同构，你的执行验证经验可以直接变成它的记忆置信度规则。③给 DreamZero 原语位写一个 910B 版实现——WAM 接入生态的第一张门票。④用 Astar 配方处理 RPent 记忆：任务卡 + 执行结果 = 现成的演化史语料，「RL 后训练版 Astar」和「RPent 记忆蒸馏」是同一件事的两个名字。

结语带走一句

如果只带走一句话：外脑时期的最优形态正在收敛成同一个形状——通用模型当规划器、专用模型当手、验证过的经验当资产；RPent 的贡献是把这个形状做成了开源基础设施，而它攒下的每一张任务卡，都是吸收时期蒸馏进权重的现成语料。

对我们的位置：RPent 出自 RLinf 团队——同一支人马，训练侧给昇腾生态做了 RLinf，运行时侧做了 RPent。你在 910B 上的训练栈和它的运行时栈天然同源：跑通它的复现、接管它的记忆纪律、占住它的 WAM 原语位，就是把自己放进这条生态的最短路径。
