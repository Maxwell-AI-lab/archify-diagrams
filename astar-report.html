演化的最后一块拼图

一个工业 AI 系统的迭代循环有四段：提出改进方向 → 写代码 → 跑实验 → 看结果。后三段早就自动化了，第一段一直握在资深工程师手里——它依赖只存在于「这个系统自己的血泪史」里的隐性知识，GPT-5.5 也给不出对症的判断（实测还不如人类专家）。Astar（阿里×浙大，2026-08）把这块最后的拼图训进了权重：用系统自己的演化史（代码 diff + 损失曲线）当训练语料，一个 0.6B 的专用模型把「提方向」的成功率做到 54.35%——超过 GPT-5.5 的 30.71% 和人类专家的 32.29%；8B 版本 67.86%。Lazada 广告推荐系统上二十轮连续自主迭代，在线 GMV +4.86%。本报告逐机制拆解它怎么把几百条演化史炼成语料、怎么解决「验证太贵」、以及——放在我们「吸收曲线」的方向判断里看——它为什么是「编排入权重」至今最强的一块实锤。

一句话定位坐标

Astar 回答的问题是：「给这个已经在跑的 AI 系统提下一个改进方向」这件事，能不能不从人脑里来，而从权重里来？答案是可以——前提是你把它当训练任务而不是提示工程，并把系统自己的演化史当语料。这是 RSI L2（闭环自改进）第一次以「提方向」这个粒度进入生产。

事实分两档：论文级（arXiv 2608.27287，全文可查，本报告所有数字出自原文）和媒体级（机器之心的解读，用于中文语境核对，未引入额外数字）。论文八个作者来自阿里后端架构团队与浙大，系统已部署于 Lazada（阿里东南亚电商）广告召回。

先看缺口：循环的最后一个人环节问题

0.6B 打赢 GPT-5.5：隐性知识论战绩

核心评测 S@1（单次提出的方向，真实执行后损失确实下降的比例）：Astar-8B 67.86%，人类专家 32.29%，GPT-5.5 30.71%。最扎眼的数字是连 0.6B 版本都有 54.35%——参数规模差三个数量级，赢的原因只有一个：它读过这个系统的演化史，GPT-5.5 没读过。

数据炼金：几百条演化史怎么炼成语料四座大山

监督信号不是从天上来的：一份演化史只有几百条记录，一半还是「水」（日志、重构、改了个 job_name）。Astar 的四个设计每个都对着一座山——把存量资产无中生有地扩成监督，是这门手艺的核心，和 Motus2 的失败数据、DeepSeek 的任务合成是同一家族。
山问题设计
C1 数据太少演化史仅数百条，训不动两两配对扩增：任意两个版本配成样本，O(n)→O(n²)；用整条损失曲线对比自动打标
C2 满库是水commit 混日志/重构/杂项两级过滤：规则级（调用图可达性 + AST 归一化 + 配置白名单）+ LLM 级（演化意图语义判别）
C3 空间太大方向组合空间近乎无限三级层级提示：L1 粗方向（7 大类）→ L2 模块 → L3 具体动作，先粗后细地收窄生成
C4 验证太贵真跑一次实验数小时到数天学到验证器：用历史正负样本训 reward model，1 秒内预测「损失会不会降」

三级漏斗：把无限空间收窄成七张门牌搜索空间

训练三段与消融阶梯配方

Qwen3 0.6B/4B/8B 打底，mid-training（语料上继续预训练）→ SFT（只用正样本对）→ GRPO（reward model 当奖励，组大小 16）。消融阶梯告诉我们钱该花在哪一步。

学到的验证器 vs 执行的验证器最深的一层

C4 的答案是 reward model：从历史正负样本学一个「1 秒预测损失会不会降」的代理评估器（AUC 0.8487），当 RL 的奖励也当推理时的预筛。这是对 CyberGym「执行验证」路线的一次正面挑战——两条路线的取舍，是本报告认为最值得深挖的一层。

上线：二十轮连续演化与吞吐量跃迁生产

两个被论文精选取出的方向样本，说明它提的不是万金油：①观察到生成式召回中不同层级（RQ-VAE 码本层）学习难度异质，提出层级专用解码器 FFN→MoE，用确定性层级路由，FLOPs 中性；②观察到 Muon 优化器的正交化在噪声主导的推荐场景会放大噪声，提出谱去噪：用 Marchenko-Pastur 律给出噪声边界 σth=σnoise(1+√γ)²，边界内的奇异值衰减、边界外的照常正交化——零可学习参数。诚实标注：S@1 0.68 意味着仍有约三分之一的提案无效，案例是高分样本；但「0.68 vs 人类 0.32」的两倍差距是全量测出来的。

放进吸收曲线：这是哪一块实锤方向判断

我们此前的方向下注：认知职能持续从脚手架/人脑迁入权重（「编排入权重」），吸收时刻的确认信号是「更小的专用模型在领域内打赢外挂的通用大模型」。Astar 同时给出了两样：被吸收的职能是「提演化方向」——此前最像「人的判断」的环节；证据形态是 0.6B 碾压 GPT-5.5。吸收曲线在算法演化这个域上第一次全段走完。

RSI 框架对位与监督对齐家族框架

放进我们《递归自演进》的三级划分：GPT-5.5 基线组是 L1（工具性使用——模型没变强，只是被调用）；Astar 是工业级 L2（输出回流改权重，且进入生产拿真金白银的 A/B）；论文的未来工作（多轮反思、创新者/批评者/验证者多智能体共判）在往 L3 的门槛张望但未跨过——训练 Astar 的管线本身还不是 Astar 改进的对象。六十年无人实现 L3 的判断不变，但 L2 的「生产化深度」又加了一层：从改权重（STaR/Self-Rewarding）到改任务（DeepSeek 任务合成）再到改整个工业系统（Astar），回流的箭头越来越粗。

系统错配形态解法
Motus2失败数据被当模仿目标监督路由：失败 → 仿真/评估模式
DeepSeek V4.1合成任务与验证系统错配五角色工厂 + 防破解审计
GE-Act 2.0生成未来与录制动作 mode 错配KASO 高噪声探针 + 噪声重放
Astar演化记录混入非因果噪声（日志/重构）；配对样本可能不同批不可比两级意图过滤 + 曲线打标；RM 周期执行审计校准漂移

监督对齐家族凑成四家了，而且 Astar 补上了家族里缺的那一环：代理验证器自身的漂移对齐（前三家对齐的是监督与条件，这一家对齐的是评估器与真值）。值得留意的同源风险：Astar 的回训闭环意味着它的输出会逐渐主导自己的训练分布——自我消耗的分布漂移和 DeepSeek「低信息增益内容=隐性重复」是同一头兽，RM 审计环是目前看到的缰绳。

对我们的映射：你的演化史就是语料落地

这份论文对我们最值钱的不是结论，是配方可以直接抄：12 节点 910B 集群上跑 CyberGym + RL 后训练的每一次实验——git 提交、reward 曲线、S1-S3 评测轨迹——就是一份现成的「演化史」。照 Astar 的流水线处理它，就能训一个「RL 后训练版 Astar」。

具体五步：①导出实验历史（代码 diff + 训练曲线 + 评测结果），实验快照按提交对齐；②两两配对——reward 曲线对比打标，振荡惩罚项直接照抄（RL 训练的抖动问题比推荐系统更尖锐）；③两级过滤——配置白名单（学习率/优化器/GRPO 超参保留，节点数/输出路径丢弃）+ LLM 意图过滤（只留显式训练策略改动）；④层级提示——L1 粗方向可先分：奖励塑形 / 训练超参 / 数据配比 / 基础设施策略 / 评测方法；⑤Qwen3-4B 打底 mid-train → SFT → 训 RM——而你的执行验证（S1-S3）正好当 RM 的审计锚，这是 CyberGym 路线和 Astar 路线的天然合体点。产出：一个 0.6-8B 的「下一个实验做什么」提案器，910B 单卡可部署，把你的试错吞吐从每周 Θ(10) 提到 Θ(100)。这不是替代你的判断——是把「哪些方向显然不值得试」这个最耗时的初筛外包给读过全部历史的模型。

结语带走一句

如果只带走一句话：「提出改进方向」是 AI 系统迭代循环里最后一个被认为不可能自动化的人类职能，Astar 用 0.6B 证明它和写码、评估一样——只要演化史在，它就能被训进权重；人在循环里剩下的，只有决定建什么，和守住什么是真的。
